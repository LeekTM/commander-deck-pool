Submit a deck

Paste your exported decklist (MTGGoldfish "Exact Card Versions", Moxfield export, Archidekt export-to-text, or an EDHREC list all work). This page checks every card against Scryfall before you submit — typos, banned cards, and cards outside your commander's colour identity are caught here, not after the fact. Submitting opens a prefilled GitHub issue, so you'll need a GitHub account.

Click a tag to select it. There's no fixed list — these are just every tag already used in the pool, so reuse one if it fits, or add your own. Leave none selected if you're not sure.

Bracket is normally computed from the count of Game Changers in the deck: 0 → 2, 1–3 → 3, 4+ → 4. That can't tell 1 from 2 or 4 from 5, and brackets are partly about expected game length now — override it here if the computed value looks wrong for how the deck actually plays. This is a sorting hint, not a ruling.
