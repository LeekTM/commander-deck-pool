Submit a deck

Paste your exported decklist (MTGGoldfish "Exact Card Versions", Moxfield export, Archidekt export-to-text, or an EDHREC list all work). This page checks every card against Scryfall before you submit — typos, banned cards, and cards outside your commander's colour identity are caught here, not after the fact. Submitting opens a prefilled GitHub issue, so you'll need a GitHub account. There's no name field — the deck's name in the pool is generated automatically as "<Commander> (Bracket N)" once you validate.

Just the name(s) — two lines if there's a partner pair. Double-faced commanders work either way: "Esika, God of the Tree" or "Esika, God of the Tree // The Prismatic Bridge". No need to type "Commander" or a quantity, that's handled for you.

The other 99 cards, straight from your export — no "Deck" header needed either.

Leave this on "Calculate" unless you have a reason not to. The bracket is worked out from the count of Game Changers in the deck (0 → 2, 1–3 → 3, 4+ → 4), and on "Calculate" it is recalculated every time the pool rebuilds — so it follows the Game Changers list when WotC revises it, instead of freezing at whatever it was the day you submitted. Pick a number only to pin one: that count can't tell 1 from 2 or 4 from 5, and brackets are partly about expected game length now, so a deck that plays nothing like its calculated number is worth pinning by hand. Either way this is a sorting hint, not a ruling.

Click a tag to select it. There's no fixed list — these are just every tag already used in the pool, so reuse one if it fits, or add your own. Leave none selected if you're not sure.
